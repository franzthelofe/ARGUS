###### Where is ARGUS designed to go that humans and dogs can't — narrow voids, unstable multi-story rubble, underground pockets?
	ARGUS can go to narrow voids, unstable multi-story rubble and underground pockets depending on the environment.

###### Where is this technology meant for deployment geographically — e.g., earthquake-prone regions like the Philippines?
	It is meant for earthquake-prone area and can be use anytime by rescuers when necessary.

###### Where does the data it gathers go — a local command post, cloud storage, a rescuer's handheld device?
	The data go to the rescuers handheld device like their personal smartphone that can be controlled by the rescuers.
